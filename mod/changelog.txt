Version: 0.7.0
Date: 2026-10-10
  Major Features:
    - Graphs: build a program from nodes and wires, like Unreal blueprints, in the program's own workshop (Programs window → New graph). The palette has nodes for the whole machine API, plus If, loops, Try, variables and your own functions; red wires carry the flow, green wires carry data. Check and Publish show errors right on the nodes; the code built from the graph is shown read-only.
  Features:
    - Red and green wire buttons in the workshop palette (no Circuit network research needed).
    - Move nodes with cut and paste (Ctrl+X, Ctrl+V): their wires move with them.
    - Debugging in the workshop: nodes show where each machine running the program is; pick a machine to set breakpoints on nodes, step and continue.
    - Graph programs travel in exchange strings together with their graph.
    - The machine window shows the graph node next to the current line.
  Info:
    - Player guide: "Graphs: programs without code" (Russian and English).

Version: 0.6.0
Date: 2026-10-10
  Features:
    - Fuel slot in the machine window: standing next to a machine, click it with fuel in hand to refuel the machine, with an empty hand to take the fuel out.
    - Cargo in the machine window: click with an item in hand to put it into the cargo, click an item with an empty hand to take it to your inventory.
    - refuel(item, robot): a machine refuels another Mk1 machine within reach from its own cargo; the other machine's program does not have to do anything.
    - Other machines' fuel is visible to programs: robot.fuel (0..1), within sight.
  Bugfixes:
    - The player guide said fuel goes "into the machine window", but there was no way to do it.

Version: 0.5.0
Date: 2026-10-09
  Major Features:
    - Debugger: the Debug… button in the machine window. Click a line number to set a breakpoint (for this machine only), step line by line, continue or pause; the program's variables, its modules' variables, me.memory and parameters are shown next to the code.
    - In-game help (F1 or the shortcut bar): first steps, common errors and every function of the machine API with search and examples to copy.
  Features:
    - All machines window (shortcut bar): every machine of the team with its program, state and fuel; filters for errors, no fuel and idle, sorting; a click shows the machine through remote view and opens its window. The Machines: N button in the program window opens it for that program.
    - Blueprints keep machines with their program and parameters: a built machine starts its program right away and gets a new name.
    - API descriptions in English: the help, the VS Code types and the new program template follow the game language.
  Changes:
    - Step in the machine window now runs to the next line of the program.
  Info:
    - Documentation in English: README, player guide, language and VS Code guides.
    - Programs published before 0.5.0 have no breakpoints until rebuilt: the debug window offers Rebuild for debugging.

Version: 0.3.0
Date: 2026-10-09
  Major Features:
    - Modules: import and export between team programs, own libraries, folders in the program list; updating a library rebuilds the programs that use it. Starter library "lib/Помощники".
    - Program editor: code opens with syntax highlighting; click a line to edit it, compile errors are shown in red on their lines.
  Features:
    - Program picker with search and recently used programs; copy and paste machine settings; the Programmer tool assigns a program to selected machines.
    - Messaging by subscription: subscribe(robot, topic) and publish(topic, data) instead of broadcasting to every machine.
    - VS Code: a separate program folder per save; programs in src mirror the game both ways (deleting or renaming a file deletes or renames the program); TypeScript plugin that flags unsupported language features and shows how many ticks a loop takes; "Refresh from folder" button; the sync tool updates itself.
    - print and console.log show objects, arrays, Map, Set, class instances and game objects.
    - Demo factory of red and green science: /am-science (admin).
  Changes:
    - broadcast is removed: programs that use it get a compile error with a hint to use publish and subscribe.
    - Rich text in the code editor is turned off: "[item=iron-plate]" in a program stays text.
    - Mod windows close when the mod is updated.
  Bugfixes:
    - Cyrillic text could be corrupted at the end of words when trimmed.
  Optimizations:
    - 10 000 machines with programs and subscriptions run at 60 UPS (about 5.4 ms per tick).
  Info:
    - Documentation with animations from the game; MIT license.

Version: 0.2.0
Date: 2026-10-08
  Major Features:
    - Belts, drills (including the pumpjack), inserters, logistic robots and chests (except the storage chest) and the offshore pump are removed; recipes and the technology tree are repaired.
    - Programmable automatons: TypeScript programs compiled in the game, shared team program library, editor with line numbers and error highlighting, publishing from VS Code.
    - Type checking of programs on publish.
  Features:
    - Freeplay start with two automatons, markers and seven example programs.
    - Fluids: machine tank, pump / fill / drain, crude oil with depleting yield, uranium mining with sulfuric acid.
    - Worker models Mk2 and Mk3, charging station, 18 upgrade technologies, research-gated API.
    - setRecipe, build, deconstruct, rotate.
    - Messaging between machines, shared board, task queues, pixel displays, signal markers for circuit networks.
    - Combat automatons with machine gun and rocket launcher: attack, guard, patrol, reload.
    - Flying automatons with calculated straight-line flight.
    - Tips and tricks for automatons.
  Optimizations:
    - Zone and per-tick scan caches, lazy copies of broadcast data: 300 machines with programs add about 0.6 ms per tick, 100 000 flying haulers about 1 ms.
  Info:
    - Storage schema version and migrations.
