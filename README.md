# Automaton

**Factorio без конвейеров.** Оверхол для Factorio 2.0 (только base): конвейеров, буров, манипуляторов,
логистических роботов и прибрежного насоса нет — их работу делают **автоматоны**, машины, которые
выполняют ваши программы на TypeScript. Завод строится не из лент, а из маршрутов и алгоритмов.

![Фабрика красной и зелёной науки на машинах](docs/media/factory.gif)

*Фабрика из сохранения `automaton-science`: машины копают уголь, железо и медь, плавят, возят воду
к котлу, кормят сборщики и лаборатории. Ни одного конвейера.*

```ts
// Программа «Шахтёр»: копает и возит в сундук у метки
const field = scan.resources().find((p) => p.item === "coal")!.nearest
while (true) {
  move(field)
  mine("coal")
  move(marker("склад"), { radius: 2 })
  put(scan.entities({ type: "container" })[0], "coal")
}
```

## Что есть

- **Язык** — строгое подмножество TypeScript: классы, интерфейсы, лямбды, деструктуризация, `Map`/`Set`,
  `try`/`catch`, проверка типов при публикации. Действия машины просто ждут конца — без `async`/`await`.
- **Редактор в игре** с номерами строк и подсветкой ошибок, библиотека программ команды с версиями
  и папками, **публикация из VS Code** при сохранении файла.
- **Модули**: программы импортируют друг друга (`import { chestAt } from "./lib/Помощники"`) — свои
  библиотеки функций, классов и типов; изменили библиотеку — зависимые программы пересобираются.
- **Назначение программ**: окно выбора с поиском, копирование настроек машины (Shift+ПКМ / Shift+ЛКМ),
  рамка «Программатора» по десятку машин сразу.
- **Машины**: рабочие Mk1–Mk3, боевые (пулемёт, ракеты), летающие перевозчики; зарядная станция.
- **Мир для программ**: метки, зоны, зрение, жидкости в баке, строительство, наладка сборщиков.
- **Совместная работа машин**: сообщения, запросы с ответом, общая доска, очереди задач, табло,
  сигналы цепей.
- **Мультиплеер**: всё детерминировано, 300 машин с программами — около 0.6 мс на тик.

## Установка

1. Архив `automaton_<версия>.zip` со страницы [Releases](https://github.com/zawert879/factorio-automanton/releases)
   (или собранный `npm run package` в `dist/`) — без распаковки в папку `mods` игры:
   Windows `%APPDATA%\Factorio\mods`, macOS `~/Library/Application Support/factorio/mods`, Linux `~/.factorio/mods`.
2. Новая игра freeplay — в стартовом наборе два автоматона и метки, в библиотеке команды — 9 готовых программ.
3. Посмотреть готовую фабрику: `/am-science` в чате (админ) построит её рядом с вами.

## Разработка

Мод пишется на TypeScript (`src/`), TypeScriptToLua собирает Lua в `mod/` (подключена к игре симлинком).

| Команда | Что делает |
|---|---|
| `npm run build` / `npm run watch` | Собрать мод |
| `npm test` | Компилятор, рантайм, проверка типов, примеры из документации, локаль (Lua 5.2, без игры) |
| `npm run test:game` | Внутриигровые тесты (Factorio без окна) |
| `npm run test:desync` / `test:desync:heavy` | Сохранение и загрузка посреди работы 50 машин |
| `npm run test:mp` | Выделенный сервер и клиент, подключение посреди работы |
| `npm run shot` | Снимки внешнего вида (игра с окном на секунды) |
| `npm run bench:machines` / `bench:flyers` | Нагрузочные тесты |
| `npm run demo:science` | Сохранение с фабрикой науки |
| `npm run docs:record` | Анимации для документации (`docs/media/`) |
| `npm run package` | Архив мода в `dist/` |

Подробно о проверках — [TESTING.md](docs/TESTING.md), план — [ROADMAP.md](docs/ROADMAP.md), выпуск
(тег → релиз на GitHub и портал модов) — [RELEASE.md](docs/RELEASE.md).
