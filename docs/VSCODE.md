# Писать программы в VS Code

Редактор в игре — простое текстовое поле. Большие программы удобнее писать в VS Code: он подсказывает
функции API машины, показывает документацию при наведении и подчёркивает ошибки ещё до публикации.

## Один раз: подготовить папку

1. Создайте папку для программ, например `automaton-programs`.
2. Положите в неё `automaton.d.ts` — типы API. Взять его можно двумя способами:
   - в игре: окно машины → «Программы…» → «Типы для VS Code» → Ctrl+A, Ctrl+C, вставить в новый файл;
   - из папки мода: `mods/automaton/automaton.d.ts`.
3. Рядом создайте `tsconfig.json`:
   ```json
   { "compilerOptions": { "strict": true, "target": "es2020", "lib": ["es2020"], "noEmit": true } }
   ```

## Каждая программа

1. Новый файл `шахтёр.ts` в этой папке — пишите программу. Если пишете несколько программ, добавьте
   в конец каждого файла `export {}`: так одинаковые имена в разных программах не будут мешать друг другу.
2. Скопируйте текст программы в окно «Программы команды» в игре и нажмите «Опубликовать».
3. Если в игре есть ошибки, которых не видел VS Code, — это возможности TypeScript, которых нет в языке
   машин (список — [LANGUAGE.md](LANGUAGE.md), «Не поддерживается»): `var`, `async`, регулярные выражения,
   `enum` и т. п. Текст ошибки подскажет, что заменить.

## Что знать

- Типы проверяет VS Code; игра (пока) проверяет только синтаксис и имена, а неверный тип станет ошибкой
  при исполнении. Проверка типов в игре — этап 12.
- `null` и `undefined` в языке машин — одно и то же, `==` запрещено: пишите `===`.
- Действия (`move`, `mine`, `put`…) просто ждут окончания — без `async`/`await`.
- Справка по API — [API.md](API.md), по языку — [LANGUAGE.md](LANGUAGE.md).
